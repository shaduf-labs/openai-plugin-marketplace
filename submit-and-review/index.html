Submit and review a public plugin

Prepare evidence for a first public release without confusing ZIP upload, final validation, review, approval and the developer’s Publish action.

Resolve the component roadmap first.

Adding MCP to an existing skills-only public plugin is currently unsupported. Local architectural composition does not guarantee that public upgrade route; verify the live submission path before choosing a connected roadmap and public identity.

Upload and submit. Checked 29 Sep 2026.

Upload and submit, MCP review and distribution, Submission error reference. Checked 29 Sep 2026.

Check the submitter and release identity

  • Platform eligibility. Use the appropriate organization/project, Apps Management Write role and verified identity; package files do not supply these.
  • Truthful public listing. Prepare publisher/interface metadata, required disclosures, current listing text bounds and a square icon.
  • One complete package root. Valid UTF-8/JSON/skill files, referenced assets and the final semantic version. Local portable schema requirements and final listing requirements differ.
  • Distinctive production utility. Demonstrate a real purpose and quality beyond a trial or teaching demo. Do not invent test output, approval, third-party authorization or enhanced placement.

Upload and submit, Submission error reference, Plugin guidelines. Checked 29 Sep 2026.

Skills-only and MCP require different evidence

Skills-only release
Skill checks/safety scans still apply. MCP reviewer credentials, tool demo video and five-positive/three-negative MCP cases are not required merely because the package includes a skill.
Public MCP release
Prepare a stable production publicly accessible HTTPS endpoint, domain verification, suitable auth, accurate tool schemas and annotations. Provide a dedicated reviewer sample account, an accessible demo and exactly five positive/three negative MCP cases.
UI-bearing review material
Directory screenshots no longer being displayed does not eliminate all UI review-material rules. Guidelines and submission-error references concern different contexts; verify the actual portal requirements.

Upload and submit, MCP review and distribution, Submission error reference, Plugin guidelines. Checked 29 Sep 2026.

Meeting Evidence: the honest gap list

The downloadable source demonstrates local authoring, not a completed public submission. The narrow validator covers a manifest subset/simple front matter/paths/fixtures and ZIP integrity. It is not full schema validation, host testing or an OpenAI safety validator.

  1. Behavior remains unobserved. Run and record the local invocation/negative/edge cases before asserting reliability.
  2. Public identity/listing is incomplete. Add the real publisher/interface metadata, icon and disclosures required for the actual release.
  3. Production usefulness is unproven. Establish distinctive utility instead of assuming the teaching source is accepted.
  4. Public scans and gates were not run. No installation, authentication, model test, safety scan, submission, review, approval or publication occurred in this study.
