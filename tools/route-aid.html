Decision rules and limitations

Our editorial framework: use native prompting for a one-off task; use a focused skill for repeatability; inspect an authorized integration for outside data/actions; build when a reusable workflow has no suitable existing route. These are suggestions, not measured performance or product tests.

The current guide excludes IDE plugins. Apple Messages requires Apple Silicon macOS desktop Work/Codex. Task-specific limits can override general surface support. Four catalog examples in the guide are untested.

Before a public skills-only release, plan for the current limit: adding MCP to an existing skills-only public plugin is unsupported. Local install/test is not submission, approval or publication.
